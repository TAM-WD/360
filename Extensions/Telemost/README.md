# Описание
- [Chat Downloader](https://github.com/TAM-WD/360/tree/main/Extensions/Telemost/chat-downloader) — выгрузка сообщений в Excel из личных и групповых чатов Яндекс Мессенджера и Телемоста, а также чатов трансляций. [Скачать расширение](https://github.com/TAM-WD/360/raw/refs/heads/main/Extensions/Telemost/chat-downloader/chat-downloader.zip).
- [telemost_hand_sound](https://github.com/TAM-WD/360/blob/main/Extensions/Telemost/telemost_hand_sound) - звуки при поднятии руки в Телемосте.
- [telemost_auto_recorder](https://github.com/TAM-WD/360/tree/main/Extensions/Telemost/telemost_auto_recorder) - расширение которое автоматически включает запись встречи на Яндекс Диск и конспектирование в веб‑версии Телемоста.
- [JabraTelemostBridge](https://github.com/TAM-WD/360/tree/main/Extensions/Telemost/JabraTelemostBridge) – приложение для Windows, которое позволяет включать и выключать микрофон в ПО Телемоста кнопкой на Jabra.
