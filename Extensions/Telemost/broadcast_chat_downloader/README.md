# Chat Downloader

Расширение для выгрузки переписки Яндекс Мессенджера и Телемоста в Excel: личные и групповые чаты, чаты трансляций.

[Скачать расширение](broadcast_chat_downloader.zip)

## Установка

1. Скачайте и распакуйте `broadcast_chat_downloader.zip`.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите режим разработчика.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `Chat` из распакованного архива.

Если расширение уже установлено из локальной папки, замените её файлы содержимым `Chat` и нажмите **Обновить** на карточке расширения.

## Использование

1. Откройте нужную переписку в Мессенджере или Телемосте и дождитесь загрузки сообщений.
2. Нажмите значок Chat Downloader, затем **Начать новую выгрузку**.
3. Дождитесь завершения в отдельном окне. Не закрывайте это окно и вкладку с чатом, не переключайте переписку в исходной вкладке.
4. Сохранится Excel с листами **Сообщения**, **Вопросы и ответы** и **Об экспорте**.

Вложения сохраняются как видимые названия и описания; сами файлы и медиа отдельно не скачиваются. Ответы в неоткрытых тредах автоматически не включаются. Частичный охват явно указан в окне и на листе **Об экспорте**. Если открыто несколько переписок, закройте дополнительную панель или тред.

## Проверки

Из этой папки запустите тесты модели экспорта и интерфейса (нужен Node.js):

```sh
node --test tests/export-model.test.js tests/popup.test.js
```

Для браузерных сценариев сборщика запустите из этой же папки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/tests/browser-harness.html`; проверки запускаются автоматически. Используются искусственные сообщения без данных переписки.
