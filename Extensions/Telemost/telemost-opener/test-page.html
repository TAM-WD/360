Проверка Телемоста

Ссылки /j/… должны вызвать telemost://, а /join#… — telemost://ychat/, сохранив эту страницу и число вкладок. Номера встреч вымышлены.

Проверьте обычный клик, Ctrl/Cmd+клик, Shift+клик, среднюю кнопку, затем Tab → Enter. Для локального файла включите доступ расширения к URL файлов.

  • Обычная ссылка
  • Ссылка /j/ на telemost.yandex.ru
  • Ссылка 360 с target=_blank
  • Ссылка с JavaScript-обработчиком
  • Ссылка /join#… → telemost://ychat/
  • Ссылка /join#… на telemost.yandex.ru → telemost://ychat/

Обычная ссылка внутри страницы должна работать как прежде.

Контрольная точка обычной ссылки.

Встроенный обработчик сайта выполнен: 0 раз. С включённым расширением счётчик должен оставаться нулевым.

Переход без клика по ссылке

Выделите целиком один из адресов ниже → правая кнопка → «Перейти по адресу». Новая вкладка должна закрыться, а запрос на открытие приложения — появиться в этой вкладке. Повторите тест, вставив адрес в адресную строку новой вкладки.

  • https://telemost.yandex.ru/j/123456789
  • https://telemost.360.yandex.ru/j/123456789
  • https://telemost.yandex.ru/join#room123
  • https://telemost.360.yandex.ru/join#room123

При вводе адреса в этой вкладке расширение должно вернуть эту страницу. Единственная пустая вкладка без другой загруженной вкладки остаётся с кнопкой закрытия.
