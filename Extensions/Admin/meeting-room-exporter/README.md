# Переговорные · экспорт

Расширение для Chrome, Яндекс Браузера и Microsoft Edge на Manifest V3. Выгружает каталог выбранной организации из админки Яндекс 360 в **XLSX, CSV и JSON**. Данные загружаются через открытую авторизованную вкладку.

## Установка

1. Распакуйте архив расширения в постоянную папку.
2. Откройте страницу управления расширениями браузера. В Chrome это `chrome://extensions`, в Edge — `edge://extensions`. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `meeting-room-exporter`, внутри которой находится `manifest.json`.
4. При необходимости закрепите значок расширения на панели браузера.

Если в управляемом рабочем браузере установка расширений ограничена, потребуется разрешение администратора браузера.

Для обновления замените содержимое ранее установленной папки файлами из нового архива, затем нажмите **Обновить** на карточке расширения в браузере. Закройте старую страницу выгрузки и откройте её заново значком расширения на вкладке админки.

## Актуальная выгрузка

1. Откройте [admin.yandex.ru](https://admin.yandex.ru), войдите и выберите организацию. Перейдите в раздел **Переговорные**.
2. На этой вкладке нажмите значок **Переговорные · экспорт**. Откроется отдельная страница расширения.
3. Проверьте выбранную организацию и нажмите **Загрузить из админки**.
4. После загрузки нажмите **Скачать XLSX**, **CSV** или **JSON · все поля**.

Страница расширения остаётся открытой во время загрузки. При смене аккаунта или организации в админке запустите расширение с её вкладки заново. Если организация не определилась, выберите её из списка либо введите числовой ID. ID пользователя `uid` в адресе страницы — это другой идентификатор.

## Поля

Основные колонки: **Название, Город, Расположение, Вместимость, Почта, Описание, Активирована в Телемосте, Доступна для бронирования**.

| Поле | Источник и значение |
|---|---|
| Активирована в Телемосте | `is_bound`: подключение комнаты к Телемосту, «Да» или «Нет» |
| Доступна для бронирования | `can_book`: разрешено ли бронировать комнату, «Да» или «Нет» |
| Расположение | Название офиса и этаж, как в исходном интерфейсе |
| Город | Город комнаты; при отсутствии — из справочника офисов |
| Описание | Текст из карточки комнаты, без домысливания |

Дополнительные колонки содержат офис, этаж, адрес офиса, ID комнаты и офиса, тип ресурса и другие поля, возвращённые API. Новые поля API автоматически добавляются в XLSX и CSV. Неизвестный булев статус выводится как **Не указано**, а не как «Нет». Комнаты с отключённым бронированием или Телемостом включаются в каталог.

XLSX — книга Excel с листом **Переговорные**, закреплённой шапкой, фильтрами и переносом текста. Вместимость и этаж сохраняются числами, идентификаторы — текстом. Текст, похожий на формулу, остаётся текстом. XLSX и CSV содержат одинаковые колонки и все комнаты, включая строки за пределами предпросмотра.

CSV содержит UTF-8 BOM, разделитель `;` и строки CRLF для открытия в Excel. Если Excel не разделил столбцы, используйте импорт **Из текста/CSV**, кодировку **UTF-8** и разделитель **точка с запятой**. Значения, похожие на формулы, экранируются для безопасного открытия в таблицах. В JSON исходные значения сохраняются без такого преобразования, включая `null`, `false` и `0`.

JSON содержит `rooms` и `offices` с исходными объектами ресурсов, организацию, время выгрузки, число комнат и предупреждения. Служебная оболочка API с ключами сессии в него не попадает.
